(WIP) Electric Vacation
Roguelite FPS
Overview
This is my current work-in-progress project. My aim is to make a roguelite fast-pased fps, while conducting user testing to improve game flow. Although this proejct is still early in development, I spent a bit of time figuring out how I wanted to general movement to feel. I also spent some time working on other game systems that I thought were fun, like a custom voxel collision system for particles.
