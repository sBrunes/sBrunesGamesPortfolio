Gait VR
Physical Therapy for TBI patients
Overview
This is a VR therapy application made for an on-going research project. In the study, Physical Therapists aid patients with Traumatic Brain Injury (TBI) through their physical exercise regimen as they walk and do various exercises through these VR environments. This application was created and iterated on continuously.
I have been involved in this project for the entirety of its development, and have served as the lead developer for the application. In addition to this, I was HEAVILY involved in co-designing features, and training physical therapists to operate the experience. I would frequently create prototypes for features and environments, before gathering feedback from several Physical Therapists in a rehab setting. Since patient comfort and application usability were EXTREMELY important for this project, these feedback sessions provided valuable insights that could be used to improve the overall quality.
This project proved particularly challenging due to the physical enviornment in which it would be used. While patients are wearing the headset, they are suspended from a 75-foot long straight track, so that they can walk and exercise without fear of falling. Because of this, it was absoluetely necessary to design the experience/application around the following considerations:
  • A solution for accomidating such a long physical distance with a VR headset had to be found
  • Logistics regarding deployment of such a system in a clinical environment (in a way that's unobtrusive to therapists and other patients) had to be resolved
  • Gaining access to the actual environment the application would be used in required careful planning and collaboration, so that nearby patients would not be interrupted
  • Calibration methods would have to be developed, so that the intended walking directions/areas in the virtual world would line-up with the physical straight-line track in the real world
To address these challenges, frequent collaboration and feedback was collected on rapid development. When this project was first being developed, we had planned on using Unreal Engine 5 with a wired HTC Vive Pro 2 VR headset. However, we quickly encountered several logistical problems related to usability, physical space, and tracking capabilities of the headset. Because of this, we pivoted to using the HTC Vive Focus Vision 2 mid-development.
Since this new headset we decided to use was a standalone VR headset (at least that's how we planned to use it), it could not run the resource-intensive prototype that we had previously developed. Because of this, I was tasked with recreating the entirety of the application in Unity3D, with the aim of optimizing it as much as possible.
Despite the need for rapid development and collaboration, I was able to efficiently recreate the application. We found that this new version, combined with the less-intrusive standalone headset, fit our needs for the study.
