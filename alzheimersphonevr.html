Alzheimer's Cooking VR
Research Application for Phone VR
Overview
This is an Alzheimer's research VR application meant to be run on a Samsung s25+ phone. While the full version of this application features several different types of cooking tasks, I was brought onto this project for the purpose of creating a slightly more complex "Hazelnut Chicken" recipe within a limited time frame.
During my time on this project, I was responsible for programming interactions and implementing 3D model and animation assets created for the project. In addition to this, I frequently communicated with the project leader to iterate implementation, and improve usability.
